# 🏦 Loan Approval Prediction using Machine Learning

## 📌 Project Overview

Loan Approval Prediction is a Machine Learning project that predicts whether a loan application is likely to be **Approved** or **Rejected** based on applicant information.

The project follows a complete Machine Learning workflow including:

- Data Loading
- Data Cleaning
- Missing Value Handling
- Duplicate Removal
- Feature Engineering
- Exploratory Data Analysis
- Data Preprocessing
- Model Training
- Model Comparison
- Model Evaluation
- Best Model Selection
- Model Saving
- New Applicant Prediction

This project is developed as a **Data Science / Machine Learning portfolio project** and demonstrates how a classification problem can be solved using multiple Machine Learning algorithms.

---

# 🎯 Project Objective

The main objective of this project is to build a Machine Learning system that can analyze applicant information and predict the loan approval status.

The project uses historical loan application data to learn patterns between applicant characteristics and loan approval decisions.
